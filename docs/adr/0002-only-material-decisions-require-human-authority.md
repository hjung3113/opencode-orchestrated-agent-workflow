# Only Material Decisions require human authority

The orchestrator asks the human only for a Material Decision not already
determined by the admitted request or repository policy. Choices that alter
the request boundary, a user-observable contract, durable cross-cutting
structure or operational dependency, or authority for an irreversible
external effect are material; local reversible choices that preserve those
contracts proceed as recorded assumptions or task rationale. Model confidence
is not a materiality test. This keeps human authority over product direction
without turning design, readiness, task admission, or routine workflow
transitions into approval gates.
